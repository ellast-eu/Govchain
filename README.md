## Où en est le projet

- **Verdict de faisabilité** : le noyau (délibération + jugement majoritaire + formes de gouvernance) est constructible dès maintenant ; la décentralisation totale et l'identité globale sont un horizon de plus long terme ; les fonctions régaliennes restent hors périmètre d'un outil applicatif.
- **Prochaine étape** : lancer le banc d'essai (`MVP_BANC_ESSAI.md`), pilote recommandé en *dogfooding* (le cercle Govchain se gouverne avec Govchain).
- **Points ouverts** : voir `TORESOLVE.md`.
